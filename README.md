# 张闯 · 工业设计作品集

一个由 HTML、CSS 与 JavaScript 构成的静态工业设计作品集，展示 1-STEP、LIFT 与 ANZUO 三个项目。无需安装依赖或构建。

网站地址：[https://zc2140202121-debug.github.io/](https://zc2140202121-debug.github.io/)

## GitHub Pages 部署

将本目录内的全部文件上传至 `zc2140202121-debug.github.io` 仓库的 `main` 分支，本部署包已将图片和 PDF 整理为根目录文件，可在网页中单批选择全部文件上传。`index.html` 与 `.nojekyll` 应位于仓库根目录。

在仓库的 **Settings → Pages** 中选择 **Deploy from a branch**，分支设为 **main**，目录设为 **/ (root)**，保存后等待部署完成。
